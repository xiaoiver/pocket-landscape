## 玻璃材质优化 · 2026-10-24

- 将杯身、内壁、厚底和卷口拆为四个网格和独立材质。
- 修正旧版 `minimumThickness === maximumThickness` 导致未贴图材质有效折射厚度为零的参数；瓶壁改为 2–4 mm 范围内的厚度贴图，厚底单独配置 1.1 cm。
- 瓶内场景采用线性 HDR 采样与独立背面反射层，避免 RGBA8 高光截断和递归反馈；实际浏览器采样类型为 Half Float（type 2）。
- 玻璃使用原创 131 KB 棚拍反射环境，植物布局、相机及照明保持一致用于对比。
- 修正旋转轴接缝法线；卷口以 24 个截面段生成，约 9,216 三角形，避免使用 192×192 的过密圆环。
- `npm run test:glass`：通过；检查法线、有效厚度、无循环采样、内壁显示状态，以及 HDR 支持 / 回退路径。NullEngine 中的 Canvas 仅作几何测试桩，不据此判断视觉质量。
- `npm run build`：通过。开发预览与生产预览均能加载；同构图截图使用 1280×720 视口。

限制仍包括实时投影折射近似、未模拟焦散与多次光线反弹，及未实测手机性能。HDR 采样的显存成本高于上一版。

- 生产预览补充检查：空杯俯视、关闭全部图层无残留、恢复所有图层、旋转、近距离缩放，以及三种灯光切换均正常；本轮浏览器控制台无错误或警告。
